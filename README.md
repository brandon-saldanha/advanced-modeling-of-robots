# advanced-modeling-of-robots
This repository contains lab assignments completed for the Advanced Modeling of Robots course as part of my Master's program in Advanced Robotics at Centrale Nantes.

## Overview

The labs in this repository focus on various topics covered in the course, like kinematic modelling, dynamic modelling of tree, exotic and paraller robots

## Contents

- `student_scripts/five_bar_models.py` - Modelled the kinematics and dynamics of a Five Bar Paraller Robot
- `student_scripts/biglide_models.py` - Modelled the kinematics and dynamics of a Biglide Paraller Robot
- `student_scripts/control.py` - Designed a computed torque controller with PD to follow a trajectory
